## 1. Три алгоритма из дня

**Ситуация 1. Дорога до колледжа**
- Вход: время, расписание автобусов, пробки.
- Правила: успеваю на ближнюю — иду туда; пробка 5+ — метро.
- Результат: маршрут и время выхода.

**Ситуация 2. Оплата картой**
- Вход: баланс, цена, дневной лимит.
- Правила: баланс меньше цены — отказ; остаток ниже лимита — предупреждение.
- Результат: «оплачено» / «предупреждение» / «отказано».

**Ситуация 3. Сортировка фото в телефоне**
- Вход: файлы с датой, геометкой, размером.
- Правила: по дате → по геометке → по размеру.
- Результат: разложенные папки.

## 2. Если данных станет больше

Возьму сортировку фото. Сейчас 5000 снимков — мгновенно. Если станет в миллион раз больше (5 млрд), сортировка O(n log n) перестанет помещаться в память, понадобится внешняя сортировка блоками. Группировка перебором станет узким местом — нужен индекс по дате.

## 3. Определения

**Алгоритм** — точная последовательность шагов, которая по входным данным за конечное время даёт результат. Шаги однозначны.

**Инвариант** — утверждение, истинное на каждом шаге алгоритма. Держит рамку: нарушился — ошибка. Пример: в сортировке вставками левая часть до текущего индекса уже отсортирована.
